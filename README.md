# 原資增能獎勵報到系統 (click_fjuirc)

本專案為大會與研習專用之報到、簽退與即時統計查詢系統，前端由 GitHub Pages 託管，後端串接 Google 試算表 (Google Apps Script)。

- **線上系統網址**：[https://irc2217-fjcu.github.io/click_fjuirc/](https://irc2217-fjcu.github.io/click_fjuirc/)
- **後端試算表**：[前往 Google 試算表](https://docs.google.com/spreadsheets/d/1up0RNU638zVvAtLQlmcW3zXDuNRl5aUxV1VVUcCSu5Y/edit?gid=292620472#gid=292620472)

---

## 📌 系統功能特點

1. **大會報到與簽退管理 (`index.html`)**：
   - **簽到 / 簽退 雙模式即時切換**：頂部一鍵切換「🟢 簽到模式」與「🔵 簽退模式」，方便工作人員於不同時段進行作業。
   - **LINE / 手機相機條碼掃描**：內建 HTML5 相機辨識引擎，工作人員使用手機開啟網頁並允許相機權限後，可直接對準參加者身分證背面條碼 (Code 39) 或 QR Code 連續掃描。
   - **保留手動輸入**：完整保留身分證字號手動輸入框與確認報到按鈕。
   - **掃描結果清晰反饋**：醒目顯示「**姓名**」、學校名稱、職稱、組別與「**簽到/簽退成功**」，無干擾資訊。
   - 具備防重複掃描提示 (⚠️ 重複簽到 / 重複簽退) 與成功「嗶」音效回饋。
   - 支援 4 秒自動重置清空，方便現場工作人員流暢連續作業。

2. **研習統計看板 (`query.html`)**：
   - 即時統計應到總人數、已簽到人數、未簽到人數與已簽退人數。
   - 多維度自適應篩選：簽到狀態 (已簽到/未簽到)、簽退狀態 (已簽退/未簽退)、學校名稱、組別、飲食習慣。
   - 支援關鍵字即時模糊搜尋（學校、姓名、身分證、電話、職稱、組別、備註）。
   - 支援身分證字號末 5 碼隱碼遮罩開關，保障學員個人隱私。
   - 支援一鍵匯出篩選結果為 UTF-8 CSV 檔案（含 BOM，Excel 開啟不亂碼）。

## 📊 試算表欄位結構 (固定 14 欄)

試算表第一列為標題列，系統嚴格依據下列 14 欄位依序讀寫：

| 欄位代號 | 欄位名稱 | 說明 |
| :---: | :--- | :--- |
| **A 欄** | **學校名稱** | 學員所屬學校或機構 |
| **B 欄** | **姓名** | 學員姓名 |
| **C 欄** | **職稱** | 職位或身分 |
| **D 欄** | **身分證字號** | 系統比對鍵值 (自動大寫，條碼掃描辨識欄位) |
| **E 欄** | **聯絡電話** | 聯絡手機或市話 |
| **F 欄** | **飲食習慣** | 葷、素或特殊需求 |
| **G 欄** | **去程** | 去程交通或接駁資訊 |
| **H 欄** | **回程** | 回程交通或接駁資訊 |
| **I 欄** | **備註欄** | 報名初始備註 |
| **J 欄** | **簽到** | 系統簽到成功後自動寫入時間戳記 (`yyyy-MM-dd HH:mm:ss`) |
| **K 欄** | **簽退** | 系統簽退成功後自動寫入時間戳記 (`yyyy-MM-dd HH:mm:ss`) |
| **L 欄** | **時數** | 認列研習時數 |
| **M 欄** | **備註** | 大會行政備註 |
| **N 欄** | **組別** | 活動組別 |

## ⚙️ Google Apps Script (GAS) 部署指南

若需更新或部署後端 GAS 服務：

1. 開啟 [目標 Google 試算表](https://docs.google.com/spreadsheets/d/1up0RNU638zVvAtLQlmcW3zXDuNRl5aUxV1VVUcCSu5Y/edit?gid=292620472#gid=292620472)。
2. 點擊頂部選單的 **「擴充功能」 -> 「Apps Script」**。
3. 將專案中的 [`Code.gs`](./Code.gs) 程式碼完整複製並覆蓋貼上到 Apps Script 編輯器中。
4. 點擊右上角 **「部署」 -> 「管理部署作業」**（或「新增部署作業」）：
   - 種類選擇：**網頁應用程式 (Web App)**
   - 說明：`v2.0 14欄位簽到與簽退版`
   - 執行身分：**我 (您的 Google 帳號)**
   - 誰可以存取：**所有人 (Anyone)** *(⚠️ 務必設為所有人，前端才可免登入連線)*
5. 點擊 **「部署」** 並授予權限，複製取得的 **網頁應用程式網址 (Web App URL)**。
6. 打開前端頁面 (`index.html` 或 `query.html`)，點擊頂部橫幅的 `[點此設定 API 網址]` 貼上即可永久連線！
